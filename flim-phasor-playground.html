這裡的相量不是套公式算的：右上圖那條 TCSPC 衰減直方圖 I(t) 在雷射重複頻率 f 上取第一諧波， g = ΣI·cos ωt / ΣI、s = ΣI·sin ωt / ΣI， 就是左上圖的那個點。單指數落在半徑 0.5 的萬用半圓上；混合物落在弦上； IRF 會把點旋轉並往圓心縮，背景光子會把點往原點 (0, 0) 拉。 下方的合成 FLIM 影像每個像素都有自己的相量，構成點雲；在 phasor 圖上拖曳游標可以反查是哪些像素。

分析

相量就是直方圖的第一諧波。把 I(t) 乘上 cos ωt、sin ωt 再積分，得到的就是 g、s， 和 IQ 零差解調是同一套數學。單指數的 Fourier 轉換恰好落在半圓上，所以「半圓」不是定義，是結果。 週期性激發下長壽命的尾巴會疊到下一個週期（衰減圖上的 T 線右邊其實接回左邊），但第一諧波不受影響，這是 phasor 的方便之處。

IRF 與校正。量到的直方圖是真實衰減與儀器響應 IRF 的摺積，在頻域就是兩個相量相乘：IRF 的延遲把點轉一個角度、寬度把點往圓心縮。 把「校正」關掉看看原始點跑去哪；打開後程式用一個已知 τ = 4.0 ns 的參考染料量出 IRF 相量，再把所有像素除回去。 實驗上每次換濃度、換濾片、換偵測器都要重量參考。

背景是加法，校正救不回來。均勻背景的第一諧波為零，所以它把每個點沿著「往原點」的方向拉，比例正好是 b。 校正是乘法，只會旋轉縮放，對加法性的偏移無能為力，所以實作上要先扣背景、再校正。

α 和 f 不是同一個權重。擬合軟體回報的振幅分率 α₁ 是 t = 0 的高度比，phasor 弦上的位置卻由光子數分率 f₁ = α₁τ₁ / (α₁τ₁ + (1−α₁)τ₂) 決定，短壽命成分貢獻的光子遠比它的 α 少。 stats 裡另外列了 amplitude-weighted 與 intensity-weighted 平均壽命，它們和 τ_φ、τ_m 是四個不同的數，只有單指數時才全部相等。

點雲不是圓的。每個像素有 N 個光子，g、s 是 N 個 cos、sin 的樣本平均，共變異數由二次諧波決定： Var(g) = (1 + g₂ₙ)/2 − g² 再除以 N。所以靠近半圓兩端的點雲是扁的、方向沿著半圓切線， 暗像素的點雲又大得多，這就是為什麼 FLIM 軟體一定有強度門檻。關掉門檻，看細胞外那些幾十顆光子的像素把原點附近炸成一團。

游標與反查。在 phasor 圖上按住拖曳（滾輪調大小）圈一團點，影像上對應的像素會變成桃紅，衰減圖也會畫出被圈像素的合計直方圖。 這就是 phasor FLIM 的工作流程：不擬合，先在相量空間看見群集，再問這些群集在影像上是誰。 A、B 兩群細胞的 Δα 拉大一點，兩團就分開；拉小、或把 N 調低，兩團就糊在一起，這時才輪到「多收光子」或「換頻率」。

頻率與諧波。ωτ ≈ 1 時半圓上的刻度最疏、對壽命最敏感，stats 裡的「τ₁、τ₂ 弧距」就是這個分辨力。 二次諧波 2f 把所有壽命往半圓左下推，短壽命被拉開、長壽命被壓扁；同一組像素在 f 與 2f 各得一個相量，兩個一起用可以拆到三成分。
