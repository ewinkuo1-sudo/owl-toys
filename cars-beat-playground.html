CARS 拍頻遊樂場 🦉

兩束雷射為什麼一定要「不同顏色」？因為 pump 與 Stokes 疊加後的拍頻 Δ = ωp − ωs 才是真正推分子的那隻手。 當 Δ 對上化學鍵振動頻率 Ω，整片分子像被準時推的鞦韆一起盪起來， 訊號跑到 ωas = 2ωp − ωs——比 pump 更藍，天生避開螢光。 用「技術模式」切換自發拉曼 / CARS / SRS，三種拉曼技術擺在同一組座標下比。

玩法提示

沒有拍就沒有訊號。把 Δ 拉到 0，兩束同色、差頻為零，第二列的包絡整條攤平——推不動鞦韆，共振訊號消失； 掃描曲線上剩下的非零基線，就是 χNR 的非共振四波混頻背景（把 χNR 歸零它才真的是零）。

對準共振。按「對準 Ω」或把 Δ 拉到 Ω（例如脂質 2845 cm⁻¹），第三列的分子振幅 |A| 到 100%， 而且注意它落後驅動 90°——這是任何受驅振子在共振時的指紋。Δ 遠低於 Ω 時分子跟著推力同相；遠高於 Ω 時反相。 整片分子同步振動，訊號 ∝ N²（同調疊加）而且往前方射出，比自發拉曼亮好幾個數量級。

χNR 的代價。把 χNR 拉大，掃描曲線會從對稱的 Lorentzian 變成不對稱的色散線型： 峰往低波數偏移 Γ·x₊、高波數側在 Ω + Γ|x₋| 出現一個掉到基線以下的凹陷 （右側統計會即時算出這兩個位置），其中 x± = (−1 ± √(1+4χNR²)) / 2χNR。 這是 CARS 的固有痛點，也是後來 SRS 興起的原因之一。

Γ 與雷射脈寬。這裡的 Γ 是分子振動本身的半高半寬（HWHM；凝態典型 5–15 cm⁻¹，水的 O–H 帶則寬到 ~150）。 統計裡同時算出「頻寬等於 2Γ 的變換極限高斯脈衝」有多長，落在 0.5–1.5 ps 附近—— ps 雷射的頻寬剛好跟線寬同量級，光譜解析度與激發效率都不浪費，這是 CARS/SRS 常用 ps 而非 fs 雷射的原因。

自發拉曼的 anti-Stokes 為什麼幾乎沒有？切到自發模式，統計會算出 anti-Stokes／Stokes 的 Boltzmann 比值 e−hcΩ/kBT（300 K）：2845 cm⁻¹ 只有 10⁻⁶ 量級。 CARS 的 anti-Stokes 不靠熱佈居，靠的是拍頻主動把分子推起來，所以藍側才有訊號。

模型：χR(Δ) = A / (Ω − Δ − iΓ)，共振幅值取 A = Γ（峰值歸一），Γ 為 HWHM； ICARS ∝ |χNR + χR|²、ΔISRS ∝ Im χR、自發拉曼 ∝ Im χR； 分子振幅 |A(Δ)| = Γ / √((Ω−Δ)² + Γ²)、相位落後 φ = atan2(Γ, Ω−Δ)。 未含雷射脈衝頻寬的摺積、電子共振與相位匹配因子；第一張圖的橫軸比例為真（24 個 pump 週期，拍數 = 24·Δ/ωp）， 但第二張圖 SRS 的 ΔI 為了看得見已放大約 10³ 倍。波長換算 ω [cm⁻¹] = 10⁷ / λ [nm]。
